# AI powered Resume Scanner 

Build a professional AI-Powered Visual Resume Screener for recruiters.

1. Core Infrastructure (Supabase):

Integrate with Supabase to store:

Candidates: Name, Email, University, Total Years Experience.

Resumes: The raw text of the resume and the original file URL.

Match_Scores: Technical Score, Soft Skills, Experience Score (0-100).

Enable Supabase Auth for recruiter login.

2. The Recruiter Dashboard (Frontend):

Sidebar: Navigation for 'Dashboard', 'Job Descriptions', and 'Settings'.

Top Header: An 'Upload Resume' button that opens a file picker.

Job Description Selector: A dropdown to select which Job Role we are screening for (e.g., 'Frontend Intern', 'Data Scientist').

Main View: A high-end Data Table showing candidate names, their AI Match Score (color-coded: Green for >80%), and a 'Quick View' button.

3. The Visual 'Advanced' Analysis:

When a candidate is clicked, show a Radar Chart (using Recharts or Shadcn charts) that visualizes 5 metrics: 'Technical Proficiency', 'Leadership', 'Education Match', 'Project Impact', and 'Soft Skills'.

Beside the chart, show a 'Summary' card generated by AI that explains why the candidate is a good or bad fit.

4. The AI Logic (Hugging Face / Gemini Integration):

Use a Supabase Edge Function to send the resume text to a free AI model (like Llama-3 on Hugging Face or Gemini 1.5 Flash).

The AI must return a JSON object containing:

contact_info: {email, phone, linkedin}

experience_years: number

radar_stats: {tech: 80, leadership: 60, etc.}

fit_summary: 'A strong candidate with 2 years of React experience...'

5. Design Vibe:

Clean 'Enterprise SaaS' aesthetic. Use a white/slate-gray palette with 'Indigo' or 'Violet' accents. Use Shadcn/ui components for all buttons, tables, and modals
